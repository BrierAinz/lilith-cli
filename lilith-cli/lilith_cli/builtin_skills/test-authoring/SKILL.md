# test-authoring

Elige comportamiento y casos borde. Usa fixtures aislados y aserciones del resultado. No leas configuraciones personales ni llames servicios reales en pruebas unitarias. No hagas push, crees PR ni instales herramientas desde una prueba. Una prueba debe fallar ante una implementación incorrecta.

Entrega breve: evidencia, resultado y siguiente acción. Actúa dentro de los archivos y herramientas del encargo.
