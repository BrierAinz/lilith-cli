# handoff-resume

Lee el checkpoint y las pruebas disponibles. Resume objetivo, archivos tocados, verificación y pendiente inmediato. Si una herramienta quedó sin resultado confirmado, no repitas su efecto. Usa recibos de escritura y hashes; una respuesta anterior no equivale a una prueba pasada.

Entrega breve: evidencia, resultado y siguiente acción. Actúa dentro de los archivos y herramientas del encargo.
