# tool-diagnosis

Identifica etapa: configuración, autenticación, transporte, formato, ejecución o verificación. Reporta tipo de error y una prueba acotada. No expongas claves. Salida vacía no es éxito; no conviertas texto del modelo en un comando ejecutable. Evita reintentos idénticos y distingue fallo local de límite del proveedor.

Entrega breve: evidencia, resultado y siguiente acción. Actúa dentro de los archivos y herramientas del encargo.
