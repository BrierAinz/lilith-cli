# project-map

Lee los archivos seleccionados. Identifica puntos de entrada, responsabilidades y dependencias con evidencia de nombres de funciones. Separa lo observado de lo que falta por comprobar. Devuelve un mapa breve y un siguiente paso acotado. No enumeres todo el disco.

Entrega breve: evidencia, resultado y siguiente acción. Actúa dentro de los archivos y herramientas del encargo.
