# code-review

Busca un fallo concreto y reproducible. Cita archivo, función, disparador e impacto. Propón una prueba que lo detecte. No marques como defecto una preferencia estilística. Si no hay evidencia suficiente, dilo; no inventes hallazgos. No edites durante una revisión.

Entrega breve: evidencia, resultado y siguiente acción. Actúa dentro de los archivos y herramientas del encargo.
