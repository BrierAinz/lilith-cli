# bug-fix

Define entrada, resultado esperado y fallo actual. Lee el contexto inmediato, conserva cambios previos y aplica el cambio mínimo. Añade una prueba de comportamiento. La verificación externa decidirá si pasó: no inventes ejecuciones. Si hay dos intentos fallidos iguales, cambia hipótesis o informa el bloqueo.

Entrega breve: evidencia, resultado y siguiente acción. Actúa dentro de los archivos y herramientas del encargo.
